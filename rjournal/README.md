# R Journal submission: SurveyNCD

| File | Purpose |
|---|---|
| `RJwrapper.tex`, `RJournal.sty` | Official R Journal LaTeX wrapper and style (from rjtools) |
| `mia.tex`, `mia.bib` | Article source and bibliography |
| `RJwrapper.pdf` | Compiled article |
| `figures/`, `tables/` | Figures (PDF) and tables (LaTeX), generated by `analysis/` |
| `mia.R` | Reproduces every result in the article |
| `_Rpackages.txt` | R packages required |
| `motivation-letter/motivation-letter.md` | Motivating letter to the editor |

Build the PDF: `pdflatex RJwrapper; bibtex RJwrapper; pdflatex RJwrapper; pdflatex RJwrapper`.
See `../SUBMISSION_GUIDE.md` for the step-by-step submission process.
